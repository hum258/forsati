# فرصتي | FORSATI

منصة تعليم إلكتروني عربية تجمع المسارات والدورات والدروس والاختبارات ومتابعة التقدم.

## التشغيل المحلي

يتطلب Node.js وExpo CLI.

```bash
npm install
npx expo start
```

## الحالة الحالية

هذه نسخة تأسيسية للواجهة وتجربة التصفح. تسجيل الدخول، قاعدة البيانات، لوحة الإدارة، واستضافة الفيديو تحتاج إعداد الخدمات الخلفية وربطها قبل إطلاقها.
